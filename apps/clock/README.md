# Clock

A clean clock with the time on top, a thin divider, and the weekday and date below. 12- or 24-hour, six colours, any timezone.

## Setup

| Field | What to put there |
| --- | --- |
| `format` | `24h` or `12h` |
| `color` | `white`, `green`, `blue`, `orange`, `red` or `purple` |
| `lang` | `en` or `nl` — only changes the weekday abbreviation |
| `timezone` | An IANA timezone, e.g. `Europe/Amsterdam` or `America/New_York` |

**Or the quick way:** paste this into the **Parameters** field:

```
format=24h; color=green; lang=en; timezone=Europe/Amsterdam
```

Needs no internet connection and no API key.
