# Text Scroller

Shows any text you like. Short text sits still and centred; longer text scrolls smoothly and repeats.

## Setup

| Field | What to put there |
| --- | --- |
| `text` | Whatever you want to show |
| `color` | `white`, `green`, `blue`, `orange`, `red`, `purple` or `yellow` |
| `position` | `center`, `top` or `bottom` — only used when the text fits |

**Or the quick way:**

```
text=Hello World!; color=orange; position=center
```

Needs no internet connection and no API key.
